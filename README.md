# Magnetic Levitation Train System Using Permanent Magnets

## Project Description

This project demonstrates a magnetic levitation train system using permanent magnets. It reduces physical contact between the train and track, allowing the train model to move with less friction.

The system demonstrates magnetic repulsion, levitation, and smooth movement. It is designed as a small-scale model of modern Maglev train technology.

## Project Objectives

- Demonstrate magnetic repulsion and levitation.
- Understand the working principle of magnetic forces.
- Reduce physical contact between the train and track.
- Explore the application of Maglev technology in transportation.
